# 分类与边界

脚本中的规则是唯一可执行真源。本表解释决策边界，不能把文件名匹配当作已证明可以删除。

| 项目 | 默认处理 |
|---|---|
| __pycache__、.pytest_cache、node_modules 等缓存/依赖 | 可清理候选；若含重要配置、数据库、凭证、链接或保护项，提升为需确认或禁止整体删除 |
| 普通 *.log、*.tmp、logs/、tmp/ | 候选；目录内有源码、文档、数据库、配置或凭证时转为需确认 |
| dist、build、target、虚拟环境、打包程序内的依赖 | 需确认：可能是交付文件或正在使用的运行环境 |
| *.db、*.sqlite、*.fdb、*.gdb、配置、.env、*.pem、*.key | 需确认；删除前强制备份并校验 |
| js、samples、captures、*.html、导出样本、调试脚本、*.bak | 需确认：可能是源码、模板、测试资源或仍需使用的备份 |
| 浏览器 profile、IndexedDB、LevelDB、Local Storage | 持久化数据，需确认；*.log 可能是数据库事务日志 |
| src/lib/smali 等命名空间中的 log/temp | 按源码保留 |
| __init__.py、__main__.py、文档、启动文件、普通源码 | 保留 |
| .git、keys、id_rsa/id_ed25519 等已识别私钥 | 保护项；不能通过 --confirm 放行 |
| 符号链接、Windows 目录联接、非常规文件 | 跳过并报告；含这些条目的候选目录禁止整体删除 |
| 无法读取的内容 | 报告错误，禁止实际清理；不能忽略错误继续删除 |

## 临时目录的边界

tmp/ 中可能存放测试安装包、数据库快照、源码或凭证。这些内容的价值不能由目录名判断，必须逐项核实。日志目录中的配置和历史数据同理。

node_modules 中存在源码是正常现象，不因此判为源码目录；但不能把打包交付目录内的 node_modules 当普通开发缓存直接删除。

## 扫描及删除的一致性

扫描器和删除器共用分类函数。目录候选合并计数，不再同时列入子项；普通源码树递归查找嵌套缓存。

扫描指纹基于相对路径、类型、大小、修改时间及文件标识。删除和备份前复核这些元数据；这不是内容哈希，也不是文件系统锁。发现变化应停止并重新扫描，不把报告当永久删除授权。

备份必须位于清理根目录外，所有成员写入成功且通过 ZIP CRC 校验后才允许继续。需确认项仅能由重复的 --include 参数明确选择，--confirm 不能批量确认所有敏感条目。
